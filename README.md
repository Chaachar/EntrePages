## Introduction

Etudiante en BTS SIO option SLAM, EntrePages est un projet personnel réalisé dans le cadre d'un portfolio. Il a surtout pour objectif de monter en compétence dans les langages du web. 
EntrePage sera une bibliothèque collaborative où les utilisateurs pourront référencer leurs livres afin de les proposer à l'emprunt aux autres.
